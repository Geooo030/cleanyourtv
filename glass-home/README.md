# Glass Home

为这台小米电视定制的原生 Android 玻璃桌面。与上游 `launcher/` 独立构建，保留上游代码。

首页依次固定云视听小电视、内置 Apple Music、无线投屏、云视听极光。Apple Music 直接打开首页内置音乐面板，云视听极光打开已安装的 `com.ktcp.video` 电视应用。1.3 的布局参照上游 `docs/inputs-menu.jpg`，左上显示时钟和日期，顶部保留“小米原主页”、网络和设置，底部横向玻璃应用栏；全部应用和动态壁纸控制保留在下方。动态视频素材保持不变。

当前版本为 1.6.8（构建 18，延续回滚后的玻璃卡片布局）。顶栏从左至右为单色 Apple 矢量图标（小米原主页入口）、HDMI、Wi-Fi 和设置，均为纯图标按钮。HDMI、Wi-Fi 使用透明下拉面板；信号源读取系统输入列表与连接状态，使用本机 Xiaomi `EXTSRC_PLAY` 和整数 `input` 切换。Wi-Fi 面板展示真实连接状态与 IP，网络密码等系统操作保留系统设置入口。常用应用卡片不再显示英文子标题。

主页时钟在 1920×1080 设计画布上采用 120px、Inter 600 字重，使用等宽数字保持时间变化时宽度稳定；日期和分隔线根据时钟宽度留出间距。正常分钟变化时，只有变化的数字以 620ms 缓出向上滑出、下一位从下方滑入，冒号和其余数字不动。时钟单独在小尺寸 View 内绘制，不让动画逐帧重画主页；回到前台或系统时间跳变时直接校准，系统关闭动画时也直接更新。

时钟右上方显示「东莞」、天气线条图标、摄氏温度和天气状态；使用东莞市中心坐标 23.01797, 113.74866，向 [Open-Meteo](https://open-meteo.com/) HTTPS 接口请求当前模型天气，不申请定位权限。前台每 15 分钟后台更新，离开桌面取消请求，失败 5 分钟后重试；本地缓存最多保留 6 小时可见数据，更新失败或数据超过 1 小时会标注上次更新时间，没有可用数据时显示「—°」。屏幕标明数据来源，时间使用东莞所在的 Asia/Shanghai 时区。天气数据遵循 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，中文状态名称和矢量图标由 WMO 天气代码映射。

设置入口展开右上角的玻璃控制中心：顶部显示时间、日期，以及待机、电源选项、刷新桌面、设备信息、动态壁纸、系统设置六个圆形按钮；中部为亮度、音量胶囊滑条；底部为输入源卡片。左右键调节滑条，上下键切换控件，返回关闭。亮度写入 Android 系统亮度，音量读取和控制媒体音量；安装脚本开启修改系统设置权限。待机和电源菜单通过现有无障碍服务调用系统动作，设备不支持时明确提示；刷新按钮只重建桌面。展开使用 360ms 缓出缩放、下滑和淡入，收起为 240ms；快捷按钮共享一个 300ms 滑动高亮，连续输入从当前位置接续，图标使用 220ms 连续过渡，滑条使用 160ms 缓出；继续复用 240×135 壁纸模糊采样，不做整屏实时模糊。

设置面板的模糊层覆盖降低至 44%，圆环为 50%，增加动态壁纸透出。控制中心打开期间暂停视频帧回读与模糊采样，复用打开前的玻璃色彩缓存，动态壁纸继续播放；主页、面板玻璃底板分别缓存为硬件图层；按钮与滑动高亮独立更新，避免焦点动画每帧重画整块底板。开合过渡临时缓存整块面板，结束后恢复分层，关闭时恢复正常采样。

亮度、音量滑条未选中时采用低对比度玻璃填充，焦点进入时再平滑提亮。按确认键（或轻点滑条）以 280ms 过渡展开独立圆形玻璃调节器，设置面板暂时淡出；圆环缩小为 336px，中央为 82px 太阳／扬声器图标，细进度圆环表达当前大小；滑条和圆环均不显示数字或百分比。太阳光芒与声波随数值平滑变化，静音时显示扬声器叉号。精确数值仅保留在无障碍描述中。左右／上下键调节，再次确认、返回或点空白处以 200ms 收起并恢复原滑条焦点。圆环和滑条共用数值动画与系统读写，主页键直接关闭整个设置浮层。滑条仍可拖动调节，轻点只展开，不改变数值。

所有操作提示统一放在屏幕底部固定位置，随焦点切换：旧提示以 90ms 淡出、新提示以 180ms 淡入，再以 2600ms 周期柔和扫光与呼吸提亮。设置面板内不再显示快捷按钮说明、滑条操作说明，圆环下方也不显示提示；全部应用、壁纸、Wi-Fi、HDMI 复用相同底部提示。功能名称和连接状态保留。提示单独在小尺寸 View 内重绘；隐藏、失焦或关闭后停止动画，系统禁用动画时显示静态文字。

顶栏焦点使用 300ms 缓出过渡：图标放大 18%、上移 4px，高亮玻璃底座在按钮间平移，图标颜色由白色渐变为深色。连续输入从当前动画状态衔接。

常用应用使用单层透明玻璃卡片：移除整排模糊底板与卡片的重复模糊叠加，使用约 2%–6% 白色渐变、细描边和轻量焦点高光，动态壁纸直接透出。图标、文字与选中高光分别缓存在小尺寸硬件图层；切换应用只更新缩放、上移和高光透明度，应用安装状态在恢复前台时查询。首页静止时缓存整个前景，焦点移动时恢复分层，结束再缓存；视频可见时隐藏被其完全遮住的静态备用壁纸。

「全部应用」展开为玻璃浮层，以六列网格展示可启动应用的真实图标，支持方向键滚动选择、确认打开、返回关闭，关闭后焦点回到「全部应用」。主屏动态壁纸继续播放。主页键也可直接关闭浮层并回到主页。

壁纸使用左右分栏透明面板：左侧为名称、介绍和轮播开关，右侧为「动态 / 静态」标签与封面网格。动态素材为夏威夷海岸、旧金山海湾、地球北美极光、苏格兰高地，每张封面由对应视频第一个解码帧提取，只显示静态图片。选择封面预览介绍，确认才应用。动态、静态页和标签高亮共用 340ms 横滑动画；在动态壁纸最右列再按右键，会进入静态页并选中第一张，按左键返回刚才的动态位置。轮播默认关闭；开启后，当前片段完整结束才切换下一段，以末帧覆盖解码准备阶段，并用 950ms 淡化衔接首帧，只保留一个视频解码器。关闭后单张循环；选择暮色山海静态壁纸会暂停视频且不参与轮播。选择和开关保存在本地偏好中。

静态标签包含「暮色山海」和用户提供的「GOGO」小狗壁纸。每张图片独立加载封面，静态选择单独持久化，重建桌面后恢复；静态壁纸均不参与动态轮播。GOGO 从原始 6240×4160 照片等比例缩小到 1920×1280，电视上居中裁切填满 16:9 屏幕；封面按需下采样缓存，切换时仅更新一次小尺寸玻璃底色。

「全部应用」与常用应用共用 240×135 的壁纸模糊采样和低透明度玻璃材质，只在面板内绘制，不再整屏实时虚化主页。展开时主页文字和卡片淡出，壁纸继续播放；过渡期间暂停采样读取，结束后恢复。应用图标提前在后台读取并栅格化，面板布局就绪后才开始展开动画；选中时没有背景框，仅图标以 210ms 缩放。方向键跨出可见行时，网格以 320ms 缓出滑动；连续输入从当前位置重定向，鼠标滚轮也复用平滑滚动。焦点立即移动，确认键打开当前选中的应用。

应用启动显式指定电视主屏；独立预览显示的实验已撤回，主页不创建应用嵌入窗口或后台预加载应用。云视听小电视启用防录屏标记，电脑同步页面会提示其画面限制。

背景支持本地 HEVC 航拍视频，夏威夷保留原有 4K 素材，新增三款使用 Apple CDN 的 1080p SDR 版本。离开桌面就暂停。首页不循环回读视频或计算模糊；仅在视频开始、打开面板时请求一次小尺寸玻璃采样，普通面板停稳后每 400ms 更新，控制中心保留一次快照。采样使用异步 PixelCopy，三遍分离式模糊放在后台线程，旧请求在播放器更换或桌面关闭后丢弃；主页玻璃卡片不依赖这些快照。壁纸无网络播放、广告、账号或常驻视频后台服务。动态素材保存在应用专属目录，不打进 APK；尚未复制的素材会标注「素材尚未就绪」。来源见 `design/rotation-sources.json`。

字体为 Inter（英文／数字）+ Source Han Sans CN（中文），使用真正的 300、400、500、600 字重。可安装到 Windows，也能嵌入 Android；不是 SF Pro 或苹方。完整字体许可在 `assets/licenses/`，也会打包进 APK。

## 电脑端实时展示（React）

### 首页应用预览

焦点停留在云视听小电视、Apple Music、云视听极光时，首页中间偏右显示只读玻璃预览；无线投屏与顶栏、底栏不显示预览。焦点不会离开应用卡片，只有按确认才启动应用或进入完整音乐面板。小电视展示哔哩哔哩热门视频封面和标题，极光展示腾讯视频电视剧频道热播剧集；极光优先采用官方大封面，统一请求 960px 宽、90 质量的图片，并用版本化地址更新旧缩略图缓存；推荐内容每 7 秒向右滑动切换两张封面，最后一组后循环回到第一组；离开焦点或打开面板会停止轮播。数据通过配对电脑服务每 30 分钟刷新，加载失败时保留已有缓存并标示更新时间。

音乐播放时显示封面、歌名、歌手、同步歌词与进度；没有当前播放时显示最近一次成功播放的歌曲。最近歌曲元信息、封面与播放进度保存在电视私有目录，重开首页也能展示；进入「正在播放」可恢复歌曲和位置，按播放续听。播放期间每 5 秒保存一次，暂停与正常退出时更新。预览仅对局部视图执行淡入、轻微平移与缩放，不启动视频应用，不加载应用真实页面，也不持续执行全屏模糊。

### 首页音乐播放器

第二张常用应用卡片由网易云应用改为内置 Apple Music 风格入口，第四张为云视听极光。焦点停留时先显示首页右侧音乐预览，按确认才展开完整玻璃音乐面板，网易云扫码登录后首先显示资料库，左侧切换爱心歌单、收藏歌单与创建歌单，默认按收藏时间倒序显示最新爱心歌曲；支持搜索单曲和歌单，以及封面与曲目并排的歌单详情。选歌直接在 Glass Home 内播放，播放页左侧为封面和控制，右侧为平滑滚动歌词；有逐字时间戳时从浅白渐进高亮，其他歌曲按行同步。当前行以 640ms 的平移和轻微放大过渡进行追踪，文字布局预先缓存，不在动画中重新排版。资料库与歌曲列表右侧常驻当前 / 上次播放封面预览；在歌单网格最右列再次按右键，或在歌曲列表按右键，会滑动进入播放页。顶部「正在播放」显示歌曲封面图标。音乐面板使用单一半透明玻璃焦点在按钮、歌单和歌曲之间平滑移动。

支持上一首 / 下一首、暂停、进度跳转和自动续播；浏览歌单、搜索或关闭面板不会切断当前音乐，离开首页时暂停。Apple Music 卡片右上角的白色圆角波形根据当前歌曲的实际音频能量起伏。电脑端音乐服务的安装、加密登录保存和运行方式见 [`music-service/README.md`](music-service/README.md)。音乐服务与电视监控相互独立。

按 Home 返回桌面时仅关闭面板，继续播放当前歌曲；真实离开首页或休眠时暂停。生命周期回归可运行 `./tests/test-music-visibility.ps1`，覆盖返回 Home、短暂切换、加载中返回及后台暂停。

配套项目在 [`tv-mirror/`](tv-mirror/README.md)，通过 ADB + scrcpy 将电视当前屏幕实时同步到电脑浏览器，电脑端只展示电视屏幕和遥控器，支持截图与全屏。

安装 Node.js 22.12+ 和 ADB 后，在 `glass-home` 目录执行：

```powershell
./start-mirror.ps1 -TvHost 192.168.31.81
```

首次启动自动执行 `npm ci`，随后打开 <http://localhost:5173>。电视与电脑需在同一局域网，电视开启 ADB 调试并授权电脑。IP 可以在网页“连接”中修改；其他电脑可加 `-AdbPath 'C:/Android/platform-tools/adb.exe'`，端口被占用可加 `-Port 5174`。按 Ctrl+C 停止服务。

也可以进入 `tv-mirror`，手动执行 `npm ci`、`npm run dev`。该 React 项目与 Android APK 独立运行；显示的是电视真实画面，Home 按钮直接返回已安装的 Glass Home。

## Android 构建与安装

在 PowerShell 中执行 `./build.ps1`。需要 JDK 17 和 Android SDK 34，默认使用工作区 `.local-tools/` 中准备好的工具；可以传 `-JavaHome`、`-SdkRoot`。产物为 `output/glass-home.apk`。签名密钥只保存在本地 `.signing/`，不要提交。

构建后执行：

```powershell
./install.ps1 -TvHost <电视IP> -WallpaperFile ./design/hawaii-4k-sdr.mov
```

另外安装三款轮播素材时增加 `-WallpaperDirectory ./design`，该目录应包含 `san-francisco.mov`、`earth-aurora.mov`、`scotland.mov`。首帧封面已随 APK 打包。

小米固件对第三方 HOME 有白名单。常规默认桌面设置在这台 HyperOS 2 / Android 14 上无效，所以使用系统绑定的无障碍服务实现 Home 路由。启用路由后持续请求 Home 按键过滤，在第一次按下时直接打开 Glass，配对吞掉松开和长按重复事件，避免先显示小米主页。Glass 恢复前台后也保持过滤，防止松开事件漏给系统。其他按键照常传递，服务不读取页面内容、输入文字、账号或密码。原有窗口监听仅用于开机、唤醒或绕过按键过滤的系统调用兜底。

顶部“小米原主页”入口通过系统全局 Home 动作主动进入原桌面，实体 Home 仍直接返回 Glass。原桌面受签名权限保护，不能由普通应用直接启动其 Activity。ADB 的 `input keyevent 3` 在此固件上绕过实体按键过滤，不能拿它验证硬件按键防闪屏；网页遥控器使用显式 Glass 启动命令。`dumpsys activity com.gathin.glasshome` 的 `GlassHomeRouting` 输出过滤状态、实体 Home 直接路由次数与窗口兜底次数，帮助区分两条路径。`tests/test-home-key-router.ps1` 验证按下/松开、长按、重复事件、停用及其他按键；`tests/test-music-visibility.ps1` 验证 Home 返回不打断音乐。Glass 内部面板按 Home 使用原有收起动画，其他应用返回使用短淡入淡出。不会停用小米原桌面或其他系统应用。

恢复系统原主页：`./restore.ps1 -TvHost <电视IP>`。只移除本桌面的无障碍服务条目，保留其他条目。此脚本不卸载应用或删除电视数据。

`-ApplicationId com.ts.launcher` 是用于本地白名单兼容试验的构建开关；当前固件未通过此方案，因此安装版使用独立包名 `com.gathin.glasshome`，不依赖该身份。

## 素材与参考

- Apple TV 视频目录：https://aerial-videos.netlify.app/ 。所选 Hawaii 的 4K SDR 文件源自 Apple CDN；原始来源和候选链接记录在 `design/aerial-shortlist.json`。视频约 4 分钟，3840×2160，30000/1001 fps。视频素材不适用本项目代码的许可证。
- 暮色山海静态壁纸使用内置 ImageGen 工具生成；GOGO 为用户提供的照片，仅做尺寸适配。来源与生成提示词记录在 `design/asset-provenance.json`。
- Inter：https://github.com/rsms/inter ，SIL Open Font License 1.1。
- Source Han Sans：https://github.com/adobe-fonts/source-han-sans ，SIL Open Font License 1.1。
- Home 路由方案参考 Aerial 对国产电视的公开兼容说明：https://github.com/pengchujin/aerial-tv 。本模块独立实现，保留原桌面。

电视实测输出、截图和预览视频保存在本地忽略的 `output/`。重启后的持久性须另行实机确认，不能用当前会话的测试代替。

歌单分类按创建者区分：本人创建的归入「创建歌单」，收藏他人的归入「收藏歌单」。列表尚未加载或为空时，焦点保持在分类按钮；数据返回后才进入有效条目，避免空网格选择越界。

音乐封面统一使用两级缓存：16MB 解码内存与电视私有目录中最多 128MB 的原图缓存，缓存可跨面板和进程重启复用。七天内直接命中缓存；过期先显示旧图再后台刷新。相同封面请求合并，重复绑定条目保留已显示的图片，避免反复占位和闪烁。缓存按最近使用自动淘汰，损坏文件重新加载，退出账号时清理。
