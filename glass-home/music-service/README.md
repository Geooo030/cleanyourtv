# Glass Home 音乐服务

电视第二张常用卡片为内置 Apple Music 风格播放器，使用原生 MediaPlayer 在 Glass 首页内播放网易云音乐。首次进入先展示爱心歌单与收藏歌单，支持单曲 / 歌单搜索、歌单详情和同步歌词。面板关闭后继续播放；打开其他应用或电视休眠时暂停，不与电影声音争抢焦点。焦点停留先展示首页只读预览，按确认才打开完整音乐面板。

## 本机启动

需要 Windows、Node.js 22+。此目录执行 `npm ci --ignore-scripts`，然后 `./start.ps1`。服务在 5176 端口运行；电脑需保持开机并与电视连接同一局域网，与 tv-monitor 的 5173 端口互相独立。安装 FFmpeg 并加入 PATH 可启用首页波形的真实节奏起伏；未安装时音乐照常播放，波形保持静止。

安装 Glass APK 后执行 `./setup.ps1 -TvHost 192.168.31.81 -ComputerHost 192.168.31.220 -AutoStart`，将随机配对令牌写入电视私有偏好。`-AutoStart` 添加当前 Windows 用户的登录启动快捷方式，不会修改电视 ADB 设置。移除自启动时删除启动目录中的 `Glass Home Music.lnk` 即可。

当前 APK 仅允许向 `192.168.31.220` 和 `127.0.0.1` 发起明文连接，其他网站保持 HTTPS。电脑 IP 改变后，更新 `res/xml/network_security.xml` 的本地地址、重新构建安装并配对。路由器为电脑保留 DHCP 地址可以避免地址改变。若 Windows 防火墙阻止连接，只允许电视 IP 访问 Node 的 5176 端口，不应对公网开放。

## 登录与播放

电视首次打开音乐卡片显示网易云扫码登录。二维码过期时可按「刷新二维码」。登录后进入资料库，最左侧以「爱心歌单 / 收藏歌单 / 创建歌单」切换。默认直接展示爱心歌曲，按爱心歌单 `trackIds.at` 收藏时间倒序排列，不使用 `likelist` 返回顺序或歌曲 ID 排序；每次重新读取第一页时检查 60 秒刷新期限。收藏分类仅显示他人的歌单，创建分类显示本人创建的歌单；依据 `creator.userId` 归类。服务读取所有上游分页、排除爱心歌单后，再按分类独立分页，每页 30 个。分类快照缓存 5 分钟，两类请求共享一次读取；歌曲每页加载 40 首，接近底部时自动加载。搜索可在单曲 / 歌单之间切换，每页 30 个结果。浏览列表与实际播放队列互相独立，只有确认选歌时才更换队列。

确认歌曲进入播放视图：左侧封面、曲名和播放控制，右侧大字歌词。YRC 逐字时间戳用于连续高亮，只有 LRC 时按行同步；没有歌词时显示纯音乐状态。返回继续浏览时，底部迷你播放条保持可用，右侧显示当前或上次播放的封面。歌单网格最右列再按右键，以及歌曲列表按右键，均以 460ms 滑动进入播放页；返回恢复原浏览位置。顶部「正在播放」带歌曲封面图标。玻璃焦点在控件间以 360ms 平移并调整尺寸，当前歌词行以 640ms 跟随并放大约 8.5%，沿用缓存排版。播放进度条获得焦点后，左右键快进或快退 10 秒。上一首、下一首和播放 / 暂停均支持遥控器；歌曲结束自动播放下一首。顶部「账号」连续确认两次可退出登录。

上次成功播放歌曲的元信息、封面和播放进度保存在电视私有目录。播放中每 5 秒记录进度，暂停、跳转进度和正常退出时更新；只打开资料库不会自动发声。点击「正在播放」可恢复上次歌曲和位置，按播放后先完成定位再开始发声。歌曲完整结束后下次从头开始，退出网易云账号会清除记录。

首页白色圆角波形由电脑端 FFmpeg 解码当前歌曲的实际 PCM 能量驱动，采样间隔 50ms，再按电视播放进度平滑插值。无需麦克风权限；仅重绘小波形区域。歌词缓存文字布局、仅在可见时推进滚动与逐字高亮，封面颜色在切换歌曲时生成小尺寸氛围底图，不持续执行背景模糊。

Home 键关闭音乐面板并返回桌面，保留当前歌曲、进度和播放队列。`onPause` 的短暂生命周期切换不会暂停音乐；首页实际进入 `onStop` 并持续 400ms 后才暂停，期间回到首页则取消暂停。打开其他应用或休眠后的暂停状态不会在返回时强制自动播放。运行 `../tests/test-music-visibility.ps1` 可验证 Home、短暂桌面切换、加载中返回、实际离开和销毁等行为。

自制播放器通过原生 `MediaSession` 发布当前歌曲和播放状态，接收系统的播放 / 暂停、上一首 / 下一首和进度控制。音乐面板关闭后，首页上的媒体键仍控制同一个播放队列；离开首页后停用此会话。其他播放器在后台主动申请音频焦点时，首页音乐仍会暂停，需要停止另一播放器的后台播放后再恢复。

无完整播放权限的歌曲显示具体提示，不将试听冒充完整歌曲，也不使用第三方解锁源。

这台小米固件的 VLC 播放引擎会丢弃 HTTP Authorization 请求头。因此 Glass 用自己的 HTTP 客户端将音频读取到应用私有临时缓存，再通过文件描述符交给 MediaPlayer。缓存最多保留 3 首，每首最多 64MB，退出 Activity 时清理；播放时提前缓存下一首。首次选歌会有短暂加载，后续切换可复用缓存。服务由隐藏的 PowerShell 进程守护，异常退出后 5 秒重启。

## 数据与维护

- 固定依赖 `@neteasecloudmusicapienhanced/api@4.41.1`，来源 https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced 。它是非官方接口，可能随网易云接口变化需要维护。
- 歌曲地址使用实测可用的 `song_url_v1` + `crypto: eapi`；禁用解锁、代理和随机 IP。仅接受网易云官方 CDN，服务器升级为 HTTPS 并检查跳转域名。
- 网易云 Cookie 只在电脑端使用，通过 Windows DPAPI 当前用户加密写入 `.runtime/session.dpapi`。退出登录删除它；会话失效则重新扫码。
- `.runtime/config.json` 是随机 256 位配对令牌，电视仅持有此令牌，不持有网易云 Cookie。所有音乐端点要求令牌，拒绝浏览器 Origin。配对时限制运行目录访问权限；运行目录、日志、二维码和依赖均不进 Git。
- 服务对电视使用带配对令牌的本地 HTTP，只适合受信任家庭局域网；不要配置路由器端口转发。账号 Cookie 不经过此连接。
- 运行 `npm test` 验证令牌、CDN 域名、歌单分页与顺序、搜索类型映射和逐字 / 逐行歌词解析；`node --check server.mjs` 检查语法。真实播放需要电视登录后验证。

本版不提供 VIP 权限绕过或独立手机音乐控制。音乐符号为原生矢量绘制，界面借鉴 Music 的布局；音源明确标识为网易云音乐。

## 首页预览内容

配对服务同时提供 `/api/home-preview/bilibili` 和 `/api/home-preview/aurora`，分别读取 [哔哩哔哩热门接口](https://api.bilibili.com/x/web-interface/popular?ps=6&pn=1) 与 [腾讯视频电视剧频道](https://v.qq.com/channel/tv) 的公开封面和标题，不使用电视应用账号或网易云 Cookie。腾讯频道的字符串字段只作数据解析，不执行页面脚本；预览标注实际数据来源，内容不保证与电视应用的个性化首页一致。数据缓存 30 分钟，上游不可用时保留旧数据与原更新时间；缓存放在忽略的 `.runtime/` 中。封面代理限制官方图片域名、重定向目的地及响应大小。腾讯优先使用 `coverPic` 大封面，替换原有 Qpic 缩略图命令，按 `imageMogr2/thumbnail/960x/quality/90` 获取清晰且有界的图片；缓存版本升级时同时更新原生图片地址，避免沿用 175px 小封面。

推荐封面每 7 秒向右滑动一组并循环，下一组封面提前缓存；隐藏后停止计时和移动。

首页预览订阅本地播放状态不会触发扫码登录或播放操作。最近一次实际播放的歌曲元信息与封面保存在电视私有目录，退出网易云账号时清除。

## 电视封面缓存

歌曲、歌单和播放预览共用原生图片加载器：16MB 内存缓存、128MB 私有磁盘缓存。首次下载后保存编码图片，之后先读内存、再读磁盘；七天内不发封面 HTTP 请求，过期先显示缓存并后台更新。并发相同地址合并为一次请求，失败短暂退避。磁盘使用原子写入、账户配对域隔离与 LRU 自动清理，关闭面板和进程重启保留缓存，退出账号清理。封面解码限制为 1024px 最大边，防止大图占用过多内存；图片数据只在后台线程读写和解码。资料库条目重复绑定相同封面时保留现图。

`dumpsys activity com.gathin.glasshome` 的 `GlassArtwork` 仅输出内存/磁盘命中、HTTP 尝试和失败次数，不包含令牌或图片地址。`../tests/test-artwork-cache.ps1` 验证持久化、作用域、刷新时间、容量限制、原子替换及坏缓存处理。
